# Institution logos

Official logos for the non-bank institutions in `src/lib/institution-logos.ts` (water, electricity,
waste, government, telcos, insurers, car makers, CLC). Bank and e-wallet logos live in
`public/banks/`.

Each logo is a trademark of its institution, used only to identify it, never to suggest a
partnership. To add one: put the official file here as `<key>.svg` or `<key>.png` (a square
emblem), set `logo: "/logos/<key>.png"` on its registry entry, and record its source below.
Until then the institution shows its badge in its category's colour.

Files were taken on 2026-10-12 from each institution's own website (its site icon or logo as the
page declares it), trimmed, centred on a transparent 256 px square and palette-compressed; the
artwork is otherwise unchanged.
