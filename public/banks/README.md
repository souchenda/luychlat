# Bank logos

Logos used in wallet avatars to show which bank or e-wallet a wallet belongs
to. Each logo is a trademark of its institution. It is used only to identify
that institution, not to suggest any partnership or endorsement. Files were
taken on 2026-10-05.

## Adding a bank

Put the file here, then set `logo` (and `alias` for name matching) in
`src/lib/wallets/providers.ts`.
